\question Write a function \lstinline$fahrenheitToCelsius$, which takes in an integer \lstinline$f$ and returns the temperature in Celsius.
Hint: the formula for Fahrenheit to Celcius is to subtract 32 and then multiply by 5/9.

\begin{lstlisting}
def fahrenheitToCelsius(f):
    """
    >>> fahrenheitToCelsius(32)
    0.0
    >>> fahrenheitToCelsius(104)
    40.0
    """



\end{lstlisting}

\begin{solution}
\begin{lstlisting}

def fahrenheitToCelsius(f):
    return (f - 32) * (5/9)

\end{lstlisting}
\end{solution}
