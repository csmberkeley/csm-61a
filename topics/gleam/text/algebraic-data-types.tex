\begin{blocksection}
An algebraic data type is a type built from other types in two ways: by combining them, called a product type, or by choosing between them, called a sum type.
We can implement a product type using a tuple. \lstinline{#(Int, Bool, String)} contains an Int, a Bool, and a String.
Gleam allows defining sum types by specifying variants of a type. Each variant has its own constructor. We instantiate sum types by calling a constructor of a variant.

\end{blocksection}
