Just like in Python, a \texttt{Tree} in Gleam contains a \texttt{label} and a list of \texttt{Tree}s as \texttt{branches}. \texttt{label} can be of a generic type, called \texttt{a} in our implementation. 
\texttt{leaf} returns a \texttt{Tree} with label \texttt{label} and an empty list for \texttt{branches}.
