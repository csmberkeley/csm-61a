\par\vspace{\baselineskip}
\noindent Here is some commonly used list syntax:
\begin{itemize}
  \item \lstinline|[]| is empty.
  \item \lstinline|[first, ..rest]| splits a non-empty list.
  \item \lstinline|[first, ..rest]| also constructs a new list.
  \item \lstinline|#(x, y)| is a two-element tuple.
\end{itemize}

\vspace{\baselineskip}
\noindent Here are some commonly used built-in list functions:
\begin{itemize}
  \item \lstinline{list.append(xs, ys)} joins two lists.
  \item \lstinline{list.map(xs, f)} applies \texttt{f} to each value.
  \item \lstinline{list.filter(xs, keep)} keeps values satisfying \texttt{keep}.
  \item \lstinline{list.length(xs)} returns a list's length.
\end{itemize}
